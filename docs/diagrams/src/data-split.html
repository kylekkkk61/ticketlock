What is stored where

Personal details stay off the blockchain. The facts people need to trust without asking us go on it.
Sign-in provider
{{logo:privy:20:#111111}}
A specialist service, so we never handle passwords or wallet keys.
  • Email verified with a one-time code
  • Wallet key created for the account, held securely
  • Sessions who is signed in
TicketLock server
An ordinary database. Useful, private, and not the source of truth.
  • Account link which email goes with which wallet address
  • Orders simulated checkouts and their result
  • Entry requests waiting for staff, with their short codes
  • Queue transactions being sent, so none is sent twice
Smart contract
{{logo:base:28:#ffffff}}
Public and permanent. Anyone can read it; only the rules can change it.
  • Events organiser, capacity, counts
  • Ownership which account holds each ticket
  • Use used or not, and when
  • Counters to cancel old signatures
  • History every issue, transfer and entry
Never on the blockchain
Names, email addresses and payment details. A ticket is tied to a wallet address, which on its own identifies nobody.
If our server went offline
Every ticket and its status would still be readable by anyone. New purchases and relayed actions would pause until it returned.
What still relies on trust
The platform issues tickets and runs the relayer, Privy guards the wallets, and the organiser decides whom to admit.
Rule of thumb
If losing or changing a fact would let someone cheat, it lives on-chain. If it is only for convenience, it lives in our database.
